# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the impact you expect. Reports are acknowledged, and fixes land on `main`.

## Supported versions

This is a template, so only the latest `main` is maintained. A project created from it owns its copy of the code and needs to apply fixes itself.

## Scope

In scope: the template's own code, configuration, and tests in this repository.

Vulnerabilities in a dependency belong with that dependency's maintainers. Known advisories for the packages used here are tracked by Dependabot security updates.
